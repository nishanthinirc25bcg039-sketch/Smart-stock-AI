# SmartStock AI

SmartStock AI is an inventory management app for small businesses. It helps track products, stock, suppliers, alerts, and inventory reports.

## How to open the app

1. Open the project folder.
2. Open the `outputs` folder.
3. Double-click `smartstock-app.html`.
4. Sign in using the demo details below.

## Demo login

- Username: `admin`
- Password: `SmartStock123`

This login is for a school project demonstration only. It is not secure enough for real business data.

## Features

- Dashboard with inventory statistics
- Add, edit, search, and delete products
- Record stock-in and stock-out transactions
- Prevent stock-out quantities from exceeding available stock
- Low-stock and out-of-stock alerts
- Manage suppliers and link them to products
- View reports, charts, and inventory analytics
- Export inventory and transaction reports as CSV
- Ask inventory questions using the AI Inventory Assistant

## Saving data

The app saves data in your browser. Your data stays available after refreshing the page in the same browser, but it does not automatically sync to another computer or browser. Clearing browser data may remove saved inventory.

## AI information

The AI Inventory Assistant uses the product and stock movement data saved in the app. Forecasts need enough transaction history. The app does not use an external AI API key.
